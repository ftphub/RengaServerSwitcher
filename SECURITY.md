# Безопасность / Security Policy

## Ключи и конфиденциальные данные

- **Никогда не публикуйте** `%LOCALAPPDATA%\RengaServerSwitcher\`, `settings.ini`, `settings.ini.rss.bak`, журналы с внутренними именами/IP и crashdump.
- В `profiles.json` ключи защищаются DPAPI, но это **не означает**, что весь набор настроек Renga зашифрован.
- Ключ активного сервера может появиться в собственном `settings.ini` Renga и его резервных копиях.
- Не отправляйте реальные ключи в Issue, Pull Request или скриншоты.
- Перед публикацией ошибок заменяйте реальные IP-адреса, DNS-имена, логины и пути к личным файлам тестовыми значениями.

## Сообщение об уязвимости

Не создавайте публичный GitHub Issue с секретами или деталями эксплуатации уязвимости.
Используйте **Report a vulnerability / Private vulnerability reporting**, если этот механизм включён у владельца репозитория; в противном случае сначала свяжитесь с автором через доступный приватный канал.

## Поддерживаемые версии

Текущая проверенная ветка: `1.1.2` для Renga Professional 9.3 / API 2.50. Исправления для иных версий не гарантируются.
