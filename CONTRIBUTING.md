# Сообщения об ошибках и предложения

- Для вопросов используйте GitHub Issues; перед созданием сообщения проверьте, нет ли уже такого вопроса.
- Указывайте версию Renga (например, `9.3.32980.0`), Renga Server Switcher (`1.1.2`), Windows, шаги и ожидаемый результат.
- Прикладывайте только **обезличенные** фрагменты логов/скриншотов; не публикуйте ключи, реальные IP, логины и клиентские проекты.
- Изменения исходников обсуждаются с владельцем. Поскольку проект распространяется с пометкой **All rights reserved**, не подразумевайте разрешение на производные версии без согласования.
- При изменении механизма перезапуска обязательно выполняйте ручной тест server → offline → server.
