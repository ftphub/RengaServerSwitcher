# Руководство пользователя

**Renga Server Switcher 1.1.2** · Renga Professional 9.3

## 1. Открытие модуля

Запустите Renga и нажмите кнопку **Renga Server Switcher** на основной панели. В окне отображаются режим работы, текущие параметры сервера, список сохранённых профилей и доступность проверенных серверов.

В настройках можно включить **«Показывать Server Switcher при запуске Renga»**, чтобы окно открывалось автоматически. Если опция отключена, плагин запускается по кнопке.

## 2. Добавление сервера

1. Нажмите **«Добавить»**.
2. Укажите **название профиля**, **IP/DNS**, **порт**, **имя пользователя** и **ключ доступа** (если требуется сервером).
3. При необходимости отметьте **«Автоматически синхронизировать изменения»**.
4. Нажмите **«Сохранить»**.

Для разных пользователей на одном сервере можно создать отдельные профили. Модуль предотвращает одинаковые записи.

## 3. Изменение и удаление

Выберите строку профиля и нажмите **«Изменить»** или **«Удалить»**. Для удаления показывается подтверждение; удаление текущего профиля дополнительно сопровождается предупреждением.

## 4. Проверка доступности

Выберите профиль → **«Проверить доступность»**. Результат TCP-подключения отобразится в карточке и колонке **«Доступность»**. Успешный ответ подтверждает только доступность адреса и порта, но не проверяет ключ или полномочия.

## 5. Подключение к серверу

1. Выберите профиль.
2. Нажмите **«Подключиться»**.
3. Проверьте сервер, пользователя и автосинхронизацию в окне подтверждения.
4. Подтвердите перезапуск.
5. Если проект содержит несохранённые изменения, выберите сохранение или отмените действие; вариант без сохранения требует дополнительного подтверждения.

После перезапуска приложение отображает новый сервер; выбранный профиль отмечается как активный. При уже активном профиле кнопка повторного подключения блокируется.

## 6. Автономная работа

Кнопка **«Остаться работать локально»** переводит Renga в состояние без соединения с сохранённым сервером, не удаляя профили. Для этого плагин применяет недоступный локальный адрес и перезапускает Renga; в интерфейсе отображается **«Автономная работа»**.

Если Renga уже автономна, повторный переход блокируется.

## 7. Настройки

- Автоматически показывать окно при запуске Renga.
- Запоминать последний выбранный профиль.
- Проверять доступность перед подключением.
- Показывать подтверждение перед перезапуском.
- Открыть папку журналов / данных.

## 8. Где искать логи

```text
%LOCALAPPDATA%\RengaServerSwitcher\Logs\
```

**Не прикладывайте логи и скриншоты с реальными IP, логинами и ключами к публичным обсуждениям без проверки.**
