# Совместимость

| Компонент | Состояние |
|---|---|
| Renga Professional 9.3.32980.0 | Проверено пользователем в рабочих сценариях |
| Renga API 2.50 | Используется проектом |
| Windows x64 | Целевая платформа |
| .NET 8 / WPF | Целевая среда |
| Visual Studio 2022, Release x64 | Проверенная сборка проекта |
| Renga 9.2 и старее | Не тестировалось; совместимость не заявляется |
| Более новые сборки Renga 9.x / 10.x | Не тестировалось; требуется проверка SDK и загрузчика |
| Linux/Wine | Не проверено, не заявляется |

Проверены сохранение профилей, переходы между серверными профилями, перезапуск и переход в автономную работу на указанной версии Renga. Не существует подтверждённого набора автоматизированных тестов для всех сочетаний серверов, ОС и конфигураций.
