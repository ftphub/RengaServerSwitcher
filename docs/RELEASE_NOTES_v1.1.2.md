# Renga Server Switcher v1.1.2

**Тип выпуска:** проверенная версия для Renga Professional 9.3.32980.0 / API 2.50 · **Автор:** `kartashov_ma`

## Основные функции

- Управление несколькими профилями Collaboration Server.
- Сохранение IP/DNS, порта, пользователя, ключа доступа и отдельного режима автосинхронизации.
- Выделение активного профиля, сетевой TCP-тест, журналирование.
- Диалоги подтверждения смены сервера и сохранения проекта.
- Автоматический перезапуск через отдельный helper и стратегию запуска с родительским `explorer.exe`.
- Режим «Автономная работа» с сохранением всех профилей.
- Шифрование ключей в собственном хранилище через Windows DPAPI.

## Исправления v1.1.2

- Исправлена ошибка компиляции `CS0103` для `Path` и `File` при загрузке иконки (пространство имён `System.IO`).
- Сохранена иконка, авторство `kartashov_ma` и интерфейс версии 1.1.

## Совместимость

**Проверено:** Windows x64, Renga Professional 9.3.32980.0, Renga API 2.50, .NET 8. Другие версии не проверялись.

## Установка

Закройте Renga, скопируйте все файлы подготовленной сборки в:

```text
C:\Program Files\Renga Professional\Plugins\RengaServerSwitcher\
```

См. [INSTALL.md](INSTALL.md).

## Ограничения

- TCP-тест не проверяет учётные данные.
- Локальный режим реализован через недоступный loopback endpoint, а не отдельный переключатель SDK.
- Ключ профиля защищён DPAPI, но собственные настройки Renga (`settings.ini`) могут содержать ключ в открытом виде.
- Исходный архив не содержит SDK DLL; для сборки нужен официальный Renga SDK 9.3.
