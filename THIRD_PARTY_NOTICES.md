# Сторонние компоненты

Проект использует следующие внешние интерфейсы и компоненты:

| Компонент | Назначение | Способ получения |
|---|---|---|
| Renga SDK 9.3 (`RengaCOMAPI.tlb`) | COM API / Interop для Renga | Официальный SDK Renga |
| `Renga.NET8.PluginUtility.dll` | Загрузка .NET 8 плагина в Renga | Официальный SDK Renga |
| Microsoft .NET 8 / WPF | Среда выполнения, интерфейс | Microsoft |
| Windows DPAPI / Win32 API | Шифрование профилей, управление запуском | Windows |

**Бинарные файлы SDK и сторонние DLL намеренно отсутствуют в исходном GitHub-архиве.**

В этом проекте не приводятся и не заменяются условия лицензирования SDK. Перед распространением скомпилированного плагина вместе с компонентами Renga SDK убедитесь, что такое распространение разрешено применимыми условиями правообладателя.

Данный документ не утверждает, что автор `kartashov_ma` владеет правами на сторонние компоненты.
