# История изменений / Changelog

## [1.1.2] — 2026-10-02

- Исправлена сборка команды иконки: добавлено `using System.IO;` для `Path` и `File`.
- Сохранены функции и поведение v1.1.1.

## [1.1.1] — 2026-10-02

- Добавлена пользовательская иконка на кнопку плагина в панели Renga.
- Автор/производитель изменён на `kartashov_ma`.

## [1.1.0] — 2026-10-02

- Визуальное выделение активного профиля и блокировка повторного подключения к нему.
- Блокировка повторного перехода в локальный режим.
- Информационная панель выбранного профиля и колонка результата проверки доступности.
- Улучшены окна редактирования, подтверждения перезапуска и сохранения проекта.
- Добавлено открытие каталога пользовательских данных из настроек.
- Предупреждение при удалении активного профиля.

## [1.0.9] — 2026-10-02

- Проверен переход сервер → автономная работа → сервер.
- Для локального режима используется недоступная loopback-точка подключения.
- Сохранён стабильный автоматический перезапуск через `explorer.exe` как родительский процесс.

## [1.0.8] — 2026-10-02

- Исправлена нестабильность автоматического запуска Renga после переключения на тестовой конфигурации: добавлен запуск с родительским процессом `explorer.exe`.

## [1.0.0–1.0.7] — 2026-10-02

- Разработка профилей, DPAPI, перезапуска, диагностики, автономного режима и исправления по результатам испытаний.

> Записи отражают историю проверенной разработки. Не все промежуточные версии предназначены для публичного использования.
